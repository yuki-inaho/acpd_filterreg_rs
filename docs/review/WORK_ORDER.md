# 是正作業書・完了条件（実装前に固定）

## 目的・要求

添付版を根拠に、2D/3DのFilterRegとAnalytic-CPDを独立したC++/nanobind、Rust/PyO3として提供します。
非剛体モードはFilterRegを一度実行した姿勢を固定し、そこからAnalytic-CPDの解析写像を合成します。
論文の定式化、原コード由来の最適化、今回の統合仕様、安全上の差分を混同しません。

## 実施順序

1. 全添付ZIPのハッシュ、比較対象の原ファイルと行範囲を記録する。
2. 実permutohedral格子：単体座標、重心重み、Splat、全軸Blur、Slice、ゼロ拡張を実装する。観測専用no-blurとprobreg自動切替も明示する。
3. FilterRegの0/1/2次モーメントと法線モーメント、SE(2)/SE(3) twist、重み付き最小二乗、分散を実装する。
4. ACPDを論文の無正則化・無減衰・逐次合成に戻す。q=10、原コードの次数割当、最良状態と停止条件を実装する。
5. 固定姿勢の二段階処理、再適用、保存復元、ヤコビアン、両言語の境界を更新する。
6. 添付原コードから独立した比較用実行形式を作り、式／アルゴリズムの比較試験と例外試験を実行する。
7. pixi・ビルド・文書・検証記録・ZIPを再生成し、再実行する。

## 状態の意味

PASS＝要求する証拠を今回の実行で取得。SOURCE_ONLY＝コード存在と静的確認、実行の証拠ではない。
BLOCKED＝具体的な環境阻害があり未達。FAIL＝試験で不合格。
