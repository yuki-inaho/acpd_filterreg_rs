# 原資料の対応と、黙って同一視しない差分

添付版を根拠とします。数式と原コードが食い違う場合、以下の選択を明示し、原プログラム全体とのビット一致とは呼びません。

## FilterReg / probreg

1. 論文(13)のゼロ値拡張と、§4.2の埋込み・Splat・Blur・Sliceを実装します。標準Blur版は添付probregのBSD-3-Clause実装のアルゴリズムを倍精度・64ビットキーで独立に移植しました。
2. 原FilterRegの観測専用Blur省略は、尺度sqrt(1/6)(d+1)の格子、観測のみSplat、モデルはSliceのみです。本版の `permutohedral_noblur` が対応します。
3. probregは拡張点群の格子数が0.015Nを超えるとBlurを省略します。その際にも利得1/(1+2^-d)を適用します。本版の `probreg` はこの規則を保ちます。原観測専用版にこの利得を流用しません。
4. `gmm_permutohedral_updatedvar_withblur.h` は添付版では実質的に空のガードです。そのファイルから完全実装を移植したとは称しません。
5. probregのスカラー版には近傍生成で独立キー長dを超える読出し、`compute`から内部関数へのstart未転送があります。前者を避け、後者を正しく伝達します。原コード比較ではクエリ側入力値を明示ゼロにして、登録時の本来の拡張入力と一致させています。
6. 元のfloat/shortをf64/i64にし、有限性・サイズ・座標上限を検査します。原版と丸め境界で異なる単体が選ばれる可能性があります。比較データは複数次元・Blur有無・start・逆順を含みますが、全浮動小数点入力のビット一致ではありません。
7. 論文式(16)の左更新及び原コードから回転微分は `-[p]_x` とします。本文のskewの符号説明を無批判に転記せず、変換の有限差分で検証します。
8. 原コードと同様に、回転ベクトルのRodrigues回転と独立並進増分を左から合成します。SE(3)指数写像のV(omega)vを使う更新とは区別します。
9. 事後重みは論文のw,N,M,σから計算します。原FilterRegの固定 `outlier_constant=0.2`、`m0<1e-2`打切りを同一設定として強制しません。数値的にゼロ・無支持の行を除きます。
10. probregの分散は更新前座標と固定値3を使う箇所があります。本版は次元dと更新後座標で最大尤度式を計算します。
11. probregの任意Kabsch呼出しはsqrt(責任度)で重心、責任度で共分散となる不整合を含みます。本版の任意Kabschは全て一貫した責任度です。既定twistを省略する代替ではありません。

## Analytic-CPD

1. 論文(3),(4)の直接事後を残し、underflowを避けるlog-sum-expで同じ確率を評価します。格子近似や半径打切りをACPDへ勝手に入れません。
2. 論文(11)の(y-c)^alpha/alpha!、固定原点、(20)の無正則化重み付き当てはめです。絶対写像をSVDで解き、保存上のみ恒等写像との差に変換します。
3. 元コードの2D正規方程式LDLT、3DブロックQRではなく、共有設計行列のSVDを使います。論文§3.5、付録B.7で認められた解法です。階数不足では絶対写像の最小ノルム解を選び、恒等写像に偏らせません。
4. 有効行数による次数低減は原コードどおりです。階数不足だけを理由に追加で低次数へ置き換えず、階数を記録します。qmaxは10までです。
5. 次数割当は添付 `DegreeScheduleDecreasingStages` の剰余配分まで照合しました。
6. 論文Fig.1に従い真の最小内部残差の状態を保存します。原Fitting.hの有意改善しきい値は待機回数の更新にのみ使います。微小な真の改善を最良状態から落としません。
7. 原Fitting.hは点数が等しい場合に自動で外部RMSE対応を仮定します。本版は論文付録B.8の意味的な既知対応という条件を尊重し、順不同の登録から外部RMSE停止を排除します。ベンチマーク側の既知対応評価は別に記録します。
8. 正規化中心を固定点群重心、共通尺度を固定点群RMS距離と明確に定義しました。論文は共通正規化を要求しますが、その一意な尺度式までは固定していません。
9. FilterReg姿勢固定と任意の分散継承は今回の統合仕様です。ACPD論文単体のアルゴリズムと混同しません。

## 忠実性の限界を明示する事項

論文で主張される公表速度、GPU、関節モデル、変形グラフ、実データ全件は再現していません。
本版の根拠は数式対応と独立原コードによる成分試験です。完全な元実行環境、停止判定まで含む全出力の一致や成功率再現ではありません。
格子近似・1回のGauss–Newton・数値的階数切捨てを含むため、実装全体の厳密EM単調性を主張しません。
